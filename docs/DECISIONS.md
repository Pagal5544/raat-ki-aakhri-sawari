# Decision log

- Platform: Android first.
- Engine: Godot 4.x with GDScript; version to be pinned in CI.
- Presentation: 3D first-person horror, landscape orientation initially.
- Setting: one reusable Indian sleeper-coach environment, built from original assets.
- Main loop: inspect coach at 02:15 AM; normal means front exit, anomaly means rear exit.
- Wrong choice: return to S-8; eventual progression target is S-1.
- First playable milestone: movement, inspection, two exits, feedback, five anomalies.
- Monetization: no ads in the prototype; consider rewarded hints/revive only after gameplay is stable.
- Repository: this dedicated game repo; do not mix it with existing Quiz or MCP bridge repos.
- Title: "Raat Ki Aakhri Sawari" is a working title, not legal/trademark clearance.
- Story, exact art style, supported device minimums, and release targets remain to be validated.
